# Joris Pannekeet Portfolio

Personal portfolio for a senior fullstack engineer, built as a white-armor
machine in a dark hangar. Sections are chamfered armor plates with bevels,
panel lines, bolts and printed decals. Red light from the inner frame is the
only accent. Modules dock into place mechanically and some open like hatches
to reveal the lit interior.

## Stack

- Vite, React 18, TypeScript, react-router
- GSAP with ScrollTrigger on native scroll
- Plain CSS design system in `src/index.css`

## Quick start

```bash
npm install
npm run dev
```

## Structure

```
src/
├── data/                    # Site copy (content.ts, caseStudies.ts)
├── lib/mech.ts              # Motion registry and useMechanics
├── components/Module.tsx    # Armor plate section, optional hatch
├── components/BlastDoors.tsx# First-load boot sequence
├── components/Layout.tsx    # Visor header, hangar struts, footer
└── pages/                   # Home, CaseStudies, CaseStudyDetail, HowIWork, About
```

`data/*.json` and `lib/data.ts` are generated by the backoffice editor. Do not
edit them by hand.

## Motion contract

Markup declares intent with data attributes. `useMechanics(scopeRef)` reads
them inside one `gsap.context`, builds one timeline per module and plays it
once when the module reaches 82% of the viewport.

| Attribute | Effect |
| --- | --- |
| `data-module` + `data-entry="left\|right\|drop\|rise"` | The module travels in, slams to a stop, recoils, dwells, locks on the other axis and turns its bolts. |
| `data-hatch` | After docking, the two overlay plates unlatch, crack, flood the interior with red light and retract to leave side armor. |
| `data-ratchet` | Direct children lock in one at a time. |
| `data-lit` | Lights flicker on at the end of the module timeline. `data-lit="flow"` fills downward instead. |

Recipes live in `src/lib/mech.ts` as records keyed by entry and light kind.
The open hatch position is owned by CSS (`[data-hatch='open']`), so the
markup renders open and JavaScript closes it before paint. Focusing anything
inside a module that has not played jumps its timeline to the end.

## Reduced motion

With `prefers-reduced-motion: reduce` the blast doors are skipped, no module
moves, every hatch renders open, and the static glows stay. Hover shifts are
disabled too.

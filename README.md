# Joris Pannekeet Portfolio

A portfolio you build yourself. The site is a drag-and-drop page builder: pick
blocks from the sidebar, drop them on the canvas, style each one and open the
result in a new tab with Preview. Every piece of the portfolio's content is a
block. The page is saved in `localStorage` under `portfolio-builder:v1`.

Two browser games live next to it at `/play` and `/rpg`.

## Stack

- Vite, React 19, TypeScript, react-router
- Tailwind CSS v4 and shadcn/ui (Radix), lucide icons
- dnd-kit for drag and drop

## Quick start

```bash
npm install
npm run dev
```

## Structure

```
src/
├── builder/
│   ├── model.ts         # Page model, reducer with undo/redo, parsePage, safeUrl (pure, tested)
│   ├── registry.tsx     # One table of block types; drives palette, canvas, preview and inspector
│   ├── blocks.tsx       # Block renderers, styled only through the block CSS variables
│   ├── sources.ts       # Content lookups for blocks (experience, projects, games)
│   ├── PageRenderer.tsx # Renders a list of blocks; shared by canvas and preview
│   ├── Builder.tsx      # The builder at /
│   └── Preview.tsx      # The saved page at /preview, live-updating across tabs
├── components/ui/       # shadcn/ui components
├── data/                # Site copy (content.ts)
├── game/, rpg/          # The two games; game/ui/theme.css holds their scoped theme
└── pages/               # Play and Rpg game shells
```

`data/*.json` and `lib/data.ts` are generated by the backoffice editor. Do not
edit them by hand.
